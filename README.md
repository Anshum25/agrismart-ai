# AgriSmart AI

An AI-powered crop-disease detection tool for SIH-2026.

## Core & Bonus Modules
- **Core**: Crop disease detection model and web interface.
- **Bonus A**: Smart irrigation logic.
- **Bonus B**: Weather-based intelligence.
- **Bonus C**: Sustainability score.
- **Bonus D**: GenAI farmer assistant.

## Setup & Run Instructions
1. Install dependencies: `pip install -r requirements.txt`
2. Run the application: `streamlit run app/app.py`

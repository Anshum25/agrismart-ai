## 🚀 Overview

**AgriSmart AI** is a real-time, end-to-end plant disease diagnostic platform designed for smallholder farmers. By uploading a photo of a crop leaf, farmers receive an instant disease classification, visual proof of the AI's decision via Grad-CAM heatmaps, and plain-language treatment advice generated by an LLM.

Instead of a "black box" prediction, AgriSmart provides **Explainable AI (XAI)** to build trust with agronomists and farmers alike.

### ✨ Key Features
- **Real-Time Diagnosis:** Identifies 38 distinct plant diseases across 14 crop types in < 1 second.
- **Explainable AI (Grad-CAM):** Visually highlights the lesions, discoloration, or fungal structures on the leaf that the neural network used to make its decision.
- **AI Agronomist (Groq Llama 3):** Generates actionable, plain-language treatment plans, biological control methods, and preventive measures.
- **Premium User Experience:** A stunning, glassmorphism-inspired React UI designed for maximum usability in the field.
- **Scalable Architecture:** Fully decoupled React frontend and FastAPI backend, ready for edge deployments.

## 🏗️ Architecture

AgriSmart AI uses a modern, scalable, microservice-ready architecture.

```text
agrismart-ai/
├── frontend/               # Modern React + Vite Application
│   ├── src/pages/          # React Views (Home, Diagnose, About)
│   ├── src/components/     # UI Components (DropZone, ResultCard)
│   └── src/index.css       # Custom Design System (Glassmorphism, Tokens)
│
├── backend/                # FastAPI Microservice
│   ├── main.py             # Inference API (/predict, /predict/gradcam)
│   └── requirements.txt    # Backend Dependencies
│
├── model/                  # Deep Learning Core
│   ├── train.py            # Two-phase transfer learning pipeline
│   ├── predict.py          # TF/Keras inference engine
│   ├── gradcam.py          # Gradient-weighted Class Activation Mapping
│   └── weights/            # Trained weights (.keras)
│
├── bonus/                  # Smart Farming Modules
│   └── assistant.py        # Groq Llama 3 LLM Integration
│
└── notebooks/              # Google Colab Training Notebooks
```

## 📊 Model Performance

Our model utilizes a **ResNet50** backbone with weights pre-trained on ImageNet. It was fine-tuned on the PlantVillage dataset using a two-phase progressive unfreezing strategy.

| Metric | Score | Details |
|--------|-------|---------|
| **Test Accuracy** | **98.96%** | Evaluated on an unseen 15% holdout split. |
| **Validation Accuracy** | **98.85%** | Evaluated during training (15% split). |
| **Test Loss** | **0.0324** | Categorical Crossentropy. |
| **Classes Supported** | **38** | Covers major diseases across Tomato, Potato, Apple, Corn, etc. |

*Training metrics are fully documented in `model/weights/training_metrics.json`.*

## 💻 Quick Start (Local)

Want to run AgriSmart AI locally? You'll need two terminals to start both the FastAPI backend and the React frontend.

### 1. Backend (FastAPI + ResNet50)

```bash
# Clone the repository
git clone https://github.com/yourusername/agrismart-ai.git
cd agrismart-ai

# Create a virtual environment and install dependencies
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
pip install -r backend/requirements.txt

# Start the API server
cd backend
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```
> The API will be available at `http://localhost:8000`. It will attempt to load the model weights automatically.

### 2. Frontend (React + Vite)

In a new terminal window:

```bash
cd agrismart-ai/frontend

# Install Node.js dependencies
npm install

# Start the Vite development server
npm run dev
```
> The beautiful UI will be available at `http://localhost:5173`.

## 🔑 Configuration (.env)

To enable the **AI Agronomist** (LLM advice), you need a Groq API key.

1. Get a free API key at [console.groq.com](https://console.groq.com/keys).
2. Copy `.env.example` to `.env` in the root directory.
3. Add your key:
```env
GROQ_API_KEY=your_key_here
```
*(If no key is provided, the backend gracefully falls back to generic care advice without crashing.)*

## ☁️ Deployment (Railway)

AgriSmart AI is designed for seamless deployment on platforms like [Railway.app](https://railway.app). 

1. Create a **Node.js** service for the `frontend/` directory (build command: `npm run build`, start command: `npm run preview`).
2. Create a **Python** service for the root directory (start command: `uvicorn backend.main:app --host 0.0.0.0 --port $PORT`).

## 🛠️ Tech Stack Deep-Dive

- **Deep Learning Layer:** TensorFlow 2, Keras, ResNet50, NumPy, OpenCV (for Grad-CAM image processing).
- **Inference Server:** FastAPI, Uvicorn, Python-Multipart (for high-speed image uploads).
- **Web Interface:** React 18, Vite, React Router, custom CSS (no heavy CSS frameworks).
- **LLM Agent:** Groq Python SDK (Llama 3 8B).
